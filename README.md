# Дядя Д. — личный сайт

Статический сайт со статьями на Astro. Статьи хранятся в Markdown или MDX и автоматически появляются на главной странице.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
```

## Новая статья

Создайте файл `src/content/articles/slug-stati.md`:

```md
---
title: "Название статьи"
publishedAt: 2026-08-31
description: "Необязательное описание для поисковиков"
draft: true
---

Текст статьи.
```

Пока `draft: true`, материал не появится на сайте. Для публикации замените значение на `false`.

Для обычного форматированного текста используйте `.md`. Если в статье понадобятся компоненты, галереи или сложные вставки — `.mdx`.

## Изображения

Временный локальный вариант — каталог `public/images`. Ссылка из статьи:

```md
![Описание](/images/example.jpg)
```

Позже изображения будут загружаться в публичный бакет Selectel и вставляться абсолютной ссылкой.
